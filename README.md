# PGAE-A: Physics-Guided Autoencoder with Unsupervised Feature Attention

Code, manuscript, and supplementary material for **"Physics-Guided Autoencoders
with Unsupervised Feature Attention for One-Class Structural Damage Detection"**
(PGAE-A), evaluated on the Z24 bridge benchmark.

PGAE-A is a one-class damage detector trained on healthy-state data only. It
operates on a redundant bank of physics-derived features spanning time-domain,
power spectral density (PSD), and transmissibility descriptors. The attention
temperature is selected automatically from the participation-ratio curve
without using any damage label.

## Data and feature extraction

The precomputed feature matrices are included in `code/features/` (and mirrored
in `major_revision/data/`), so every script in this repository runs without the raw
dataset or the feature-extraction pipeline. Raw Z24 acceleration data is not
redistributed here; it is available from KU Leuven on request:
https://bwk.kuleuven.be/bwm/z24.

**The code that turns the raw Z24 recordings into these feature matrices is
intentionally not included in this repository**, because it originates from a
prior, independent work — the reference implementation of Abdrabo (2024),
*"Application of Online Anomaly Detection Using One-Class Classification to the
Z24 Bridge,"* Sensors, 24(23):7866, which this paper's feature bank adapts and
accelerates. See that publication for the extraction pipeline itself.

The included matrices are:

```text
code/features/X_train_new.npy       544 x 906
code/features/X_test_new.npy         68 x 906
code/features/labels_train_new.npy  544
code/features/labels_test_new.npy    68
```

## Reproducing the original experiments

All scripts in `code/experiments/` read the included matrices from
`code/features/` and resolve their paths relative to the repository.

```powershell
cd code/experiments

# Ten-run detection results reported in the main performance table
python run_multiseed_eval.py

# Representative-run data for the analysis figures and tables
python run_figure_data.py

# Automatic temperature-selection figure
python make_fig5_knee_window.py
```

## Reproducing the major-revision analyses

`major_revision/code/` contains one script per new analysis added in response to the
reviewers: redundancy vs. attention weight, settlement-state sensitivity,
constant-feature removal, independent calibration, leave-one-state-out
validation, alternative one-class baselines, operational metrics, a
cluster-bootstrap confidence interval, and the regenerated Figure 8. Each
script reads its input from `major_revision/data/` and writes to `major_revision/results/`
or `major_revision/figures/`, e.g.:

```powershell
cd major_revision/code
python redundancy_analysis.py
python settlement_sensitivity.py
python alt_baselines.py
```

The corresponding numbers are reported in Supplementary Material Sections
S1-S5 and in the point-by-point response to reviewers.

## Regenerating the figures

- Figure 3 uses the static sensor-grid source `code/figures/z24 sensors.png`.
- Figure 5 is written directly by `code/experiments/make_fig5_knee_window.py`.
- Figure 6 can be regenerated by `code/experiments/make_fig6_contribution.py`.
- HTML/Canvas figure sources are rendered to `code/figures/png/` with:

```powershell
cd code/figures
python export_png.py
```

- Figures 1, 4, 6, 7, 8, 9, and 10 were regenerated at higher resolution during
  the revision; their sources and rendered PNGs are in `major_revision/figures/`.
