# PGAE-A: Physics-Guided Autoencoder with Unsupervised Feature Attention

Code and replication package for **"Physics-Guided Autoencoders with Unsupervised Feature Attention for One-Class Structural Damage Detection"** (PGAE-A), evaluated on the Z24 bridge benchmark.

PGAE-A is a one-class damage detector trained on healthy-state data only. It operates on a redundant bank of physics-derived features spanning time-domain, power spectral density (PSD), and transmissibility descriptors. The attention temperature is selected automatically from the participation-ratio curve without using any damage label.

## Data and feature extraction

The precomputed feature matrices are included in `code/features/`, so every script in this repository runs without the raw dataset or the feature-extraction pipeline. Raw Z24 acceleration data is not redistributed here; it is available from KU Leuven on request: https://bwk.kuleuven.be/bwm/z24.

**The code that turns the raw Z24 recordings into these feature matrices is intentionally not included in this repository**, because it originates from a prior, independent work — the reference implementation of Abdrabo (2024), *"Application of Online Anomaly Detection Using One-Class Classification to the Z24 Bridge,"* Sensors, 24(23):7866, which this paper's feature bank adapts and accelerates. See that publication for the extraction pipeline itself.

The included matrices are:

```text
code/features/X_train_new.npy       544 x 906
code/features/X_test_new.npy         68 x 906
code/features/labels_train_new.npy  544
code/features/labels_test_new.npy    68
```

## Reproducing the experiments

Every script in `code/experiments/` reads the included matrices from `code/features/` and resolves its paths relative to the repository.

```powershell
cd code/experiments

# Ten-run detection results reported in the main performance table (Table 5)
python run_multiseed_eval.py

# Representative-run data for the analysis figures and tables
python run_figure_data.py

# Automatic temperature-selection figure
python make_fig5_knee_window.py

# Alternative one-class baselines (SVM, Isolation Forest, PCA-SPE, variance-/MAD-normalized)
python alt_baselines.py

# Sensitivity to the healthy-state definition (settlement states)
python settlement_sensitivity.py

# Redundancy vs. attention weight, constant-feature removal, independent
# calibration, leave-one-state-out validation, operational metrics, and the
# cluster-bootstrap confidence interval for AUC
python redundancy_analysis.py
python constant_feature_removal.py
python independent_calibration.py
python leave_one_state_out.py
python operational_metrics.py
python block_bootstrap_ci.py
```

Each script writes its output to `code/experiments/results/`, and the corresponding numbers are reported in the published paper.

## Regenerating the figures

- Figure 3 uses the static sensor-grid source `code/figures/z24 sensors.png`.
- Figure 5 is written directly by `code/experiments/make_fig5_knee_window.py`.
- Figure 6 can be regenerated by `code/experiments/make_fig6_contribution.py`.
- Figure 8 (which distinguishes training from held-out healthy windows) is rebuilt by `code/experiments/fig8_regen_data.py` followed by `code/experiments/build_fig8.py`.
- HTML/Canvas figure sources are rendered to `code/figures/png/` with:

```powershell
cd code/figures
python export_png.py
```

or, for Figures 4, 6, 7, 8, and 9 specifically, with `code/experiments/export_png_isolated.py`.
